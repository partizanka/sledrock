# Папка для аудиозаписей СЛЕD

В эту директорию нужно загрузить аудиозаписи песен вашей группы в формате `.mp3`.

## 🎵 Как загрузить и связать реальные треки в плеере:

Сейчас плеер работает в режиме **Goth-Synth fallback** — если реальные аудиофайлы не заданы, браузер использует встроенный синтезатор на Web Audio API для генерации атмосферной, зловещей аналоговой музыки на ходу (чтобы пользователь мог нажать "Play" и сразу почувствовать атмосферу мистики!).

Чтобы плеер проигрывал ваши настоящие песни:

1. Скопируйте аудиофайлы в кодировке MP3 в эту папку (например, `track1.mp3`, `track2.mp3` и т.д.).
2. Откройте файл `js/script.js` и дополните список `TRACKS` путями к вашим реальным файлам:
   ```javascript
   const TRACKS = [
     { title: "Человек с 1000 лиц", album: "Проклятый", duration: "3:42", file: "audio/track1.mp3" },
     { title: "Призрак", album: "Проклятый", duration: "4:05", file: "audio/track2.mp3" }
   ];
   ```
3. Инициализируйте стандартный HTML5 `new Audio(track.file)` внутри функции `startSynthesizer()` в файле `js/script.js` вместо/параллельно синтезатора частот, чтобы проигрывать реальный звук по клику.
