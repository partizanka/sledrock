# Многостраничный сайт-визитка рок-группы СЛЕD (Минск)

Данная директория содержит классическую статическую версию сайта на **чистом HTML5, CSS3 и Vanilla JavaScript (JS)** с поддержкой трех языков (русский, белорусский, английский), разработанную специально согласно эстетическим требованиям коллектива СЛЕD.

## 📁 Структура папок

*   `index.html` — Главная страница с промо-блоками, тизером и релизами.
*   `about.html` — Подробная биография, состав группы, темные тайны и список достижений.
*   `discography.html` — Страница релизов со встроенным интерактивным кастомным плеером.
*   `media.html` — Фотогалерея концертов/репетиций и встроенные видеоклипы с YouTube.
*   `concerts.html` — Сетка событий и афиша выступлений с флагами прошедших событий.
*   `contacts.html` — Форма обратной связи с валидацией для заказа букинга и ссылки на соцсети.
*   `/css/style.css` — Главные стили, селекторы шрифтов Google Fonts (Oswald и Inter), готические тени, цветовые переменные.
*   `/js/`
    *   `translations.js` — Полный языковой словарь (RU/BY/EN) на чистом JS (защита от CORS-ошибок при локальном открытии).
    *   `script.js` — Координатор анимаций, логики бургера, липкого хедера, отправки формы и работы веб-плеера.
*   `/img/` — Директория для изображений (афиши, фото участников, логотипы).
*   `/audio/` — Плейлист аудиозаписей для плеера.

---

## 🚀 Как запустить проект локально

Проект разработан по технологии **Zero-Config**. Чтобы запустить сайт:
1. Распакуйте архив или скопируйте файлы на компьютер.
2. Дважды кликните на файл `index.html` в любом современном браузере.
3. **Нет никаких CORS-ошибок!** Благодаря тому, что языковые словари загружаются как обычный скрипт JS (`js/translations.js`), а не через `fetch()`, локальный сервер не требуется — сайт работает прямо по протоколу `file://`.
