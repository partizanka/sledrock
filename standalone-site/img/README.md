# Папка для изображений сайта СЛЕD

Сюда следует поместить графические файлы группы. Сейчас макет подтягивает красивые атмосферные фотографии-заглушки с сервиса `picsum.photos` с тематическими тегами.

## 📸 Как заменить заглушки на настоящие фотографии:

1.  **Логотип в шапке**:
    В файле `css/style.css` логотип задан инлайн SVG (иконка огня). Чтобы использовать вашу собственную картинку-логотип, замените блок `<svg class="logo-flame">` в шапке каждого HTML-файла на стандартный тег:
    ```html
    <img src="img/logo.png" class="logo-img" alt="СЛЕD">
    ```

2.  **Фото участников (в about.html)**:
    Сохраните портреты участников в эту папку под именами `yuri.jpg`, `alex.jpg`, `vitaliy.jpg`, `oleg.jpg`, `tatiana.jpg`, и отредактируйте пути в `about.html` или замените стили фонов:
    Слайды содержат инлайновые стили `background-image: url('https://picsum.photos...')`. Замените их на локальные пути, например:
    ```html
    <div class="member-photo" style="background-image: url('img/yuri.jpg');"></div>
    ```

3.  **Афиши событий (в concerts.html)**:
    Сохраните афиши фестивалей или клубных концертов как `gig1.jpg`, `gig2.jpg` и т.д. в эту папку, и укажите их в блоках афиш:
    ```html
    <div class="gig-flyer" style="background-image: url('img/gig1.jpg');"></div>
    ```
